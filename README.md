# Futro Box

Fujitsu Futro S500 console project.

This repository contains configuration, deployment scripts,
and launcher files for running Pekka Kana 2 on Futro S500.

Game source repository:
https://github.com/mihajlov39547/pk2-futro

Branch: futro-s500

To prepare the source:

git clone -b futro-s500 https://github.com/mihajlov39547/pk2-futro.git PekkaKana2-source
